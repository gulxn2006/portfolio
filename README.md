# Gulshan Kumar — Backend Developer Portfolio

> An editorial, high-performance interactive portfolio featuring a 100-frame hardware-accelerated canvas smooth scroll animation inspired by National Geographic Wild and Apple product scrubbers.

## 🚀 Live Demo & Features
- **Canvas Scroll Scrubbing**: 100-frame image sequence interpolated with delta-time exponential damping for buttery-smooth 60/120fps motion.
- **Nat Geo Editorial Layout**: Dual-style typography (`GULSHAN` solid gold + `KUMAR` outline stroke), central brand box, and live `01/04` vertical section tracker.
- **Tech Arsenal**: PHP 8.x, Laravel, MySQL, Antigravity, Codex, Bootstrap, HTML5, CSS3 with official vector emblems and proficiency meters.
- **Custom Technical Vector Cards**: Live API gateway, database cluster topology, and telemetry visualizers.
- **Zero Heavy Dependencies**: Pure HTML5, CSS3, and Vanilla JavaScript with 0% idle CPU footprint.

## 💻 Running Locally
Open `index.html` directly in any modern browser, or run a local server:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.

## 🌐 Deploy to GitHub Pages
1. Go to your repository **Settings** on GitHub.
2. Under **Pages**, select branch `main` and root `/`.
3. Save to deploy instantly for free!
